# 企业终端安全管理规范

## 文档信息
- 文档编号：SEC-EPT-001
- 版本：1.0
- 适用范围：企业所有终端设备（台式机、笔记本电脑、移动设备）

## 1. 终端安全基线

### 1.1 操作系统安全配置
所有企业终端应满足以下操作系统安全基线：
- 启用自动更新功能，安全补丁发布后七天内完成安装
- 启用磁盘加密（Windows BitLocker 或 macOS FileVault）
- 配置屏幕锁定，空闲时间不超过五分钟
- 禁用自动运行和自动播放功能
- 启用主机防火墙并配置入站规则
- 禁用不必要的系统服务和端口

### 1.2 终端防护软件
所有终端应安装企业统一部署的终端防护软件，包括以下能力：
- 实时文件监控和恶意软件查杀
- 网络入侵检测和防护（HIDS/HIPS）
- 漏洞利用防护
- Web 内容过滤和恶意 URL 拦截
- USB 设备控制和外设管理

终端防护软件的病毒库应每日更新，引擎版本应每月更新。

### 1.3 应用白名单
企业终端应实施应用白名单策略，仅允许运行经审批的应用程序。应用白名单应覆盖可执行文件、脚本文件、DLL 库和安装包。白名单的更新应通过统一管理平台推送，新增应用需经过安全评估和审批。

## 2. 终端威胁检测与响应

### 2.1 端点检测与响应（EDR）
企业应部署端点检测与响应（EDR）系统，具备以下能力：
- 进程行为监控和异常检测
- 文件系统活动监控
- 注册表修改监控（Windows）
- 网络连接行为分析
- 内存注入和代码执行检测
- 威胁情报关联分析

### 2.2 终端事件响应
终端安全事件应按以下流程响应：
- 自动响应：EDR 系统自动隔离恶意进程、删除恶意文件并阻断恶意网络连接
- 远程隔离：安全团队可远程将失陷终端从网络隔离
- 取证分析：保存终端内存快照、磁盘镜像和日志用于事后分析
- 清除恢复：清除恶意软件、修复被篡改的系统文件并恢复业务

## 3. 终端数据保护

### 3.1 数据加密
终端存储的敏感数据应进行文件级或文件夹级加密。终端与企业服务器之间的数据传输应使用 TLS 加密。终端磁盘应启用全盘加密，加密密钥应由企业统一管理。

### 3.2 数据备份
终端关键数据应定期备份至企业文件服务器或云端。备份频率为每日增量备份、每周全量备份。终端丢失或损坏后可从备份中恢复数据。

### 3.3 数据擦除
终端报废、转让或维修前应执行安全数据擦除。数据擦除标准应满足 NIST SP 800-88 要求。对于包含高度敏感数据的终端，应执行物理销毁。

## 4. 终端漏洞管理

### 4.1 漏洞扫描
终端应每周自动执行一次漏洞扫描。扫描内容包括操作系统漏洞、应用软件漏洞和配置缺陷。扫描结果应上报至企业漏洞管理平台。

### 4.2 漏洞修复
终端漏洞修复应按以下优先级执行：
- 紧急漏洞（正在被利用的零日漏洞）：二十四小时内完成修复
- 高危漏洞：七天内完成修复
- 中危漏洞：三十天内完成修复
- 低危漏洞：下一个维护窗口完成修复

无法及时修复的漏洞应采取临时缓解措施，如禁用受影响的功能或部署虚拟补丁。

## 5. 终端资产管理

### 5.1 资产发现与登记
企业应部署终端资产发现工具，自动识别接入网络的所有终端设备。每个终端应登记以下信息：设备编号、型号、操作系统版本、MAC 地址、IP 地址、使用人、所属部门和安全状态。

### 5.2 终端生命周期管理
终端应覆盖以下生命周期阶段：
- 采购入库：验收并登记资产信息
- 部署配置：安装企业标准镜像和安全软件
- 使用维护：定期更新、漏洞修复和合规检查
- 退役处置：数据擦除、资产注销和物理处置

每个阶段的操作应记录并纳入资产管理台账。
