# 企业云安全运营规范（样例）

## 云安全责任模型

企业使用云服务时应明确云服务商和企业的安全责任边界。基础设施安全由云服务商负责，应用安全、数据安全和访问控制由企业负责。混合云和多云环境下，各环境的安全责任应分别界定并形成书面协议。

## 云资源管理

云资源应按业务域、环境和安全等级划分虚拟网络和资源组。生产环境、测试环境和开发环境应网络隔离。云资源命名应统一规范，标签应包含业务归属、环境类型、安全等级和责任人。

## 身份与访问管理

云平台应启用多因素认证，特权账号应使用独立的堡垒机或特权访问管理系统。权限应遵循最小必要原则，定期复核权限分配，离职人员权限应在当日回收。服务账号应使用临时凭据或角色绑定，禁止在代码中硬编码密钥。

## 网络安全

云环境应配置安全组、网络 ACL 和 Web 应用防火墙。对外暴露的服务应经过 API 网关并启用限流和防重放。内部服务间通信应使用 mTLS 加密。跨区域或跨账号通信应经过安全审批。

## 数据安全

云存储应启用服务端加密，加密密钥应由企业控制。敏感数据应配置访问日志和防篡改保护。数据库应启用审计日志，记录所有 DDL 和敏感数据查询。数据跨区域传输应经过安全评估。

## 日志与监控

云环境应集中采集操作日志、网络流量日志、安全事件日志和应用日志。日志应保留不少于一百八十天。应配置实时告警规则，覆盖异常登录、权限变更、资源异常创建、数据大规模导出和安全组规则变更。

## 应急响应

云安全事件应急响应应明确事件分级、响应流程、通报机制和复盘要求。重大安全事件应在十五分钟内启动应急响应，一小时内完成初步影响评估，二十四小时内完成根因定位和处置方案。
