# 企业电子邮件安全管理规范

## 文档信息
- 文档编号：SEC-EM-001
- 版本：1.0
- 适用范围：企业电子邮件系统的收发、存储和安全防护

## 1. 邮件安全防护

### 1.1 反垃圾邮件
企业邮件网关应部署反垃圾邮件引擎，具备以下能力：
- 基于 IP 信誉和黑名单的发件人过滤
- 基于内容分析的垃圾邮件识别
- 基于机器学习的钓鱼邮件检测
- 基于 URL 信誉的恶意链接检测
- 基于沙箱的邮件附件恶意行为检测

垃圾邮件过滤的误判率应低于百分之一，漏判率应低于百分之零点五。

### 1.2 钓鱼邮件防护
企业应实施以下钓鱼邮件防护措施：
- 入站邮件应进行 SPF、DKIM 和 DMARC 验证，未通过验证的邮件应标记或拒绝
- 邮件网关应检测商务邮件欺诈（BEC）攻击，特别是 CEO 欺诈和供应商欺诈
- 外部邮件应在邮件标题和正文中添加明显的外部标识
- 邮件中的 URL 应重写并通过安全网关进行实时检测

### 1.3 邮件附件安全
邮件附件应经过以下安全检查：
- 附件类型白名单过滤，阻止可执行文件和脚本文件
- 宏检测，对包含宏的 Office 文档进行安全处理
- 沙箱动态分析，检测附件的恶意行为
- 附件中的敏感信息检测（DLP）

## 2. 邮件数据防泄漏

### 2.1 出站邮件 DLP
企业邮件应部署数据防泄漏（DLP）策略，检测并阻止以下敏感信息外发：
- 个人身份信息（身份证号、银行卡号、手机号）
- 企业商业机密（财务数据、客户列表、定价策略）
- 源代码和技术文档
- 合同和法律文件

### 2.2 DLP 响应策略
根据检测到的敏感信息类型和严重程度，DLP 应执行以下响应：
- 低风险：记录日志并通知发送者
- 中风险：拦截邮件并通知发送者和管理者
- 高风险：拦截邮件并通知安全团队进行人工审核
- 极高风险：拦截邮件、冻结发送者账户并启动安全事件响应

## 3. 邮件加密

### 3.1 传输加密
企业邮件应强制使用 TLS 加密传输，对于不支持 TLS 的收件方应降级处理或拒绝发送。企业内部邮件应使用 TLS 1.3 加密，外部邮件至少使用 TLS 1.2。

### 3.2 端到端加密
涉及敏感信息的邮件应支持端到端加密，可使用 S/MIME 或 PGP 加密。加密密钥应通过企业 PKI 体系分发和管理。加密邮件的密钥轮换周期不超过三百六十五天。

## 4. 邮件归档与保留

### 4.1 邮件归档策略
企业邮件应实施全量归档，所有收发邮件均应保留副本。邮件归档应支持全文检索和按条件查询。归档邮件的保留期限应符合法律法规和企业合规要求，通常不少于三年。

### 4.2 邮件审计
邮件系统应记录以下审计日志：
- 邮件收发记录（发件人、收件人、主题、时间、大小）
- 附件上传和下载记录
- 邮件删除和恢复操作
- 邮件规则和转发设置变更
- 管理员操作（账户创建、权限变更、策略调整）

## 5. 邮件账户安全

### 5.1 账户保护
邮件账户应启用多因素认证，优先使用硬件安全密钥或 TOTP 动态令牌。邮件账户应实施异常登录检测，包括异地登录、异常时间登录和暴力破解检测。检测到异常登录后应自动锁定账户并通知用户。

### 5.2 离职人员处理
离职人员的邮件账户应在离职当天禁用。邮件数据应根据企业保留政策进行归档。自动回复应设置为通知发件人联系替代人员。邮件账户应在保留期满后删除。
