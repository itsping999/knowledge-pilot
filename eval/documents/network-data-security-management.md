# 网络数据安全管理要求（样例）

参考来源：国务院《网络数据安全管理条例》发布信息和国家互联网信息办公室转载文本（https://www.cac.gov.cn/2024-09/30/c_1729384452307680.htm）。本文档为 KnowledgePilot 评测用摘要，不替代正式法规、监管要求或企业法律意见。

## 1. 适用目标

企业开展网络数据处理活动时，应把合规利用、风险防控、个人权益保护和国家安全保护统一纳入数据治理体系。网络数据安全管理不只覆盖数据库系统，也覆盖数据采集、存储、使用、加工、传输、提供、公开和删除等全流程活动。

## 2. 网络数据处理者基础义务

网络数据处理者基础义务包括建立网络数据安全管理制度、明确数据安全负责人、开展分类分级保护、采取技术保护措施、记录数据处理活动、保存必要日志、开展安全教育培训、制定应急预案、及时处置安全事件、配合监管监督检查。处理重要数据或者为关键信息基础设施提供服务时，还应提高保护强度并保留履责证据。

## 3. 重要数据目录和风险评估

企业应按照行业规则识别重要数据，形成重要数据目录并持续更新。重要数据处理活动应纳入风险评估，评估内容包括数据处理目的、处理方式、数据规模、数据流向、安全措施、外部共享、委托处理、出境风险和事件处置能力。发现风险隐患后应明确整改责任人、完成期限和复核结论。

## 4. 个人信息保护

涉及个人信息处理时，企业应坚持合法、正当、必要和诚信原则。重点控制告知同意、最小必要、敏感个人信息保护、个人权利响应、委托处理、第三方提供、公开披露、自动化决策和跨境提供。大型网络平台还应建立外部监督机制，并定期公开个人信息保护社会责任报告。

## 5. 应急和监督

企业应建立网络数据安全事件监测、研判、报告和整改机制。发生泄露、篡改、丢失、非法获取、非法利用或系统异常时，应根据影响范围和数据级别启动应急预案，采取止损措施，留存处置记录，并按监管要求报告。
