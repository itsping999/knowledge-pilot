# 星河制造集团财务数据治理规范（样例）

## 1. 总则

为加强集团财务数据的规范化管理，保障财务数据的真实性、完整性、准确性和及时性，防范财务数据风险，满足《企业会计准则》《会计法》《企业内部控制基本规范》以及上市公司信息披露要求，结合集团财务管理实际情况，制定本规范。本规范适用于集团总部及各子公司的财务数据采集、处理、存储、使用和销毁全过程管理。

## 2. 财务数据范围

### 2.1 数据分类

财务数据按业务属性分为以下类别：

1. 会计核算数据：总账、明细账、凭证、科目余额表和试算平衡表等。
2. 资金管理数据：银行账户信息、资金流水、现金流预测和融资记录等。
3. 成本管理数据：标准成本、实际成本、成本差异分析和成本分摊规则等。
4. 预算管理数据：年度预算、预算执行、预算调整和预算分析等。
5. 税务管理数据：纳税申报、税务筹划、发票管理和税收优惠等。
6. 财务报告数据：月度报表、季度报表、年度报告和合并报表等。
7. 审计数据：内部审计报告、外部审计工作底稿和审计调整等。

### 2.2 数据分级

财务数据按敏感程度分为以下级别：

1. 核心级：未公开的财务报告、并购重组数据、重大资产处置数据和高管薪酬数据。
2. 重要级：详细的成本数据、客户价格协议、供应商合同金额和资金计划。
3. 一般级：已公开的财务摘要、标准会计科目和通用财务模板。

### 2.3 数据所有者

财务数据的所有者按业务领域划分：

1. 总账数据：由集团财务总监担任数据所有者。
2. 成本数据：由成本管理部负责人担任数据所有者。
3. 税务数据：由税务管理部负责人担任数据所有者。
4. 资金数据：由资金管理部负责人担任数据所有者。
5. 预算数据：由预算管理部负责人担任数据所有者。

## 3. 财务数据采集

### 3.1 采集来源

财务数据采集来源包括：

1. 业务系统：ERP 系统、供应链系统、生产系统和销售系统等。
2. 外部数据：银行对账单、税务申报数据、工商登记信息和行业数据等。
3. 手工录入：费用报销、预提摊销和调整分录等。
4. 接口传输：子公司报表上报、关联方数据交换和外部系统对接等。

### 3.2 采集规范

财务数据采集应遵循以下规范：

1. 及时性：业务发生后应在规定时间内完成数据采集，月度结账数据应在结账日后 3 个工作日内完成。
2. 完整性：所有财务业务均应完整记录，不得遗漏。
3. 准确性：数据应与原始凭证一致，金额精确到分。
4. 一致性：同一业务在不同系统中的数据应保持一致。

### 3.3 数据校验

财务数据采集后应进行以下校验：

1. 借贷平衡校验：凭证借贷金额必须平衡。
2. 科目合法性校验：使用的科目必须在标准科目表中。
3. 业务逻辑校验：收入与成本配比、资产与负债对应。
4. 跨期校验：确认数据归属正确的会计期间。
5. 关联方交易校验：关联交易应标注并经过审批。

## 4. 财务数据处理

### 4.1 会计核算

会计核算应遵循以下原则：

1. 权责发生制：收入和费用按权责发生制确认。
2. 历史成本原则：资产按历史成本入账，减值按规定计提。
3. 配比原则：收入与相关成本费用在同一期间确认。
4. 谨慎性原则：不高估资产和收益，不低估负债和费用。
5. 重要性原则：重要的会计信息应单独披露。

### 4.2 期末结账

月度结账流程如下：

1. 账务检查：检查所有凭证是否已录入，科目余额是否正确。
2. 暂估入账：对未收到发票的采购进行暂估入账。
3. 折旧摊销：计提固定资产折旧和无形资产摊销。
4. 预提费用：计提工资、社保、水电等预提费用。
5. 损益结转：将收入和费用科目余额结转至本年利润。
6. 报表生成：生成资产负债表、利润表和现金流量表。
7. 跨系统对账：与银行、税务和业务系统对账。

### 4.3 关联方交易处理

关联方交易应遵循以下要求：

1. 交易识别：每笔交易应检查是否涉及关联方。
2. 价格审核：关联交易价格应具有公允性，必要时进行价格基准测试。
3. 审批流程：超过规定金额的关联交易需经董事会审批。
4. 披露要求：关联交易应按规定在财务报告中披露。

## 5. 财务数据存储

### 5.1 存储要求

财务数据存储应满足以下要求：

1. 数据库存储：核心财务数据应存储在专用的财务数据库中，与业务系统数据库物理隔离。
2. 备份策略：财务数据应每日全量备份，备份数据保留不少于 7 年。
3. 灾备要求：核心财务数据应具有异地灾备能力，RPO 不超过 1 小时。
4. 加密存储：核心级财务数据应加密存储，使用国密 SM4 算法。

### 5.2 保留期限

财务数据保留期限按以下规定执行：

1. 会计凭证：保留期限不少于 30 年。
2. 会计账簿：保留期限不少于 30 年。
3. 财务报告：永久保留。
4. 审计报告：永久保留。
5. 纳税申报表：保留期限不少于 10 年。
6. 银行对账单：保留期限不少于 10 年。
7. 发票存根：保留期限不少于 5 年。

### 5.3 归档管理

财务数据归档应遵循以下规定：

1. 年度归档：每个会计年度结束后，将当年财务数据进行归档。
2. 归档格式：电子档案应使用标准格式（如 PDF/A），确保长期可读。
3. 归档索引：归档数据应建立索引，支持按年度、科目和凭证号检索。
4. 归档验证：归档后应验证数据完整性和可读性。

## 6. 财务数据使用

### 6.1 访问控制

财务数据访问应遵循以下原则：

1. 职责分离：凭证录入、审核和过账应由不同人员执行。
2. 最小权限：用户只能访问其职责所需的财务数据。
3. 审批流程：核心级财务数据的访问需经财务总监审批。
4. 审计日志：所有财务数据的访问和操作应记录审计日志。

### 6.2 数据导出

财务数据导出应遵循以下规定：

1. 导出审批：批量导出财务数据需经部门负责人审批。
2. 脱敏处理：对外提供的财务数据应进行脱敏处理。
3. 水印标记：导出的财务文件应添加水印标记。
4. 传输加密：财务数据传输应使用加密通道。

### 6.3 报表管理

财务报表管理应遵循以下要求：

1. 报表权限：财务报表的查看权限应严格控制。
2. 报表版本：重要报表应保留版本历史。
3. 报表审核：对外发布的财务报表应经过审核。
4. 报表归档：定期归档历史财务报表。

## 7. 财务数据安全

### 7.1 安全措施

财务数据应实施以下安全措施：

1. 网络隔离：财务系统应与办公网络隔离，通过专用 VLAN 访问。
2. 终端安全：财务终端应安装防病毒软件，禁用 USB 存储设备。
3. 打印控制：核心级财务数据的打印应经过审批。
4. 拍照防护：财务办公区域应禁止拍照。

### 7.2 合规要求

财务数据管理应满足以下合规要求：

1. 会计法：确保会计资料的真实性和完整性。
2. 企业会计准则：遵循适用的会计准则进行核算。
3. 内部控制规范：建立财务数据相关的内部控制措施。
4. 上市公司信息披露：按规定进行信息披露，防止内幕交易。

## 8. 财务数据销毁

### 8.1 销毁条件

财务数据在以下条件下可以销毁：

1. 已超过规定的保留期限。
2. 经财务总监和法务部门确认不再需要保留。
3. 不涉及未决诉讼或监管调查。

### 8.2 销毁流程

财务数据销毁应遵循以下流程：

1. 销毁申请：由数据所有者提出销毁申请。
2. 审批流程：经财务总监、法务部门和信息安全部门审批。
3. 销毁执行：由信息技术部执行数据销毁，确保不可恢复。
4. 销毁记录：记录销毁的时间、范围和执行人员。

## 9. 审计与监督

### 9.1 内部审计

内部审计部门应定期对财务数据管理进行审计，审计内容包括：

1. 数据采集的完整性和准确性。
2. 数据处理的合规性和规范性。
3. 数据存储的安全性和可靠性。
4. 数据使用的合规性和权限控制。

### 9.2 外部审计配合

财务部门应配合外部审计机构的工作，提供必要的财务数据和解释。审计过程中发现的问题应及时整改。

## 10. 附则

本规范由集团财务部和信息安全部共同负责解释和修订，自发布之日起施行。
