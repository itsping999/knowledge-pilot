# 星河制造集团数据治理委员会章程（样例）

## 1. 总则

为建立健全数据治理体系，统筹推进数据治理各项工作，保障数据资产安全和高效利用，根据《数据安全法》《个人信息保护法》等法律法规，结合集团实际情况，设立数据治理委员会。

## 2. 组织架构

### 2.1 委员会组成

数据治理委员会由以下人员组成：

1. 主任委员：由集团首席信息官（CIO）担任，负责委员会全面工作。
2. 副主任委员：由首席数据官（CDO）和首席信息安全官（CISO）担任。
3. 委员：由各业务部门负责人、IT部门负责人、法务合规负责人、审计负责人组成。
4. 秘书处：设在信息安全部，负责日常协调和会议组织。

### 2.2 职责分工

委员会各成员职责如下：

1. 主任委员：审批年度治理计划、重大制度变更和跨部门协调事项。
2. 副主任委员（CDO）：负责数据标准制定、数据质量管理和数据资产运营。
3. 副主任委员（CISO）：负责数据安全策略、安全事件响应和合规审计。
4. 业务部门委员：负责本部门数据治理执行和问题反馈。
5. 法务合规委员：负责法律法规解读和合规风险评估。
6. 审计委员：负责治理执行审计和整改跟踪。

## 3. 会议制度

### 3.1 会议类型

1. 全体会议：每季度召开一次，审议重大事项和季度报告。
2. 专题会议：根据需要召开，讨论特定议题或应急事项。
3. 工作例会：每月召开一次，跟踪工作进展和解决问题。

### 3.2 会议议题

全体会议议题包括：

1. 审议年度数据治理工作报告。
2. 审批重大数据安全制度和标准。
3. 审议数据分类分级方案和调整。
4. 审批跨部门数据共享方案。
5. 审议数据安全事件处置报告。
6. 审议数据治理预算和资源分配。

### 3.3 决策机制

委员会决策采用多数表决制，主任委员有一票否决权。重大事项需三分之二以上委员出席，出席委员过半数同意方可通过。紧急事项可采用书面会签方式决策。

## 4. 数据治理职责

### 4.1 制度建设

委员会负责制定和审批以下制度：

1. 数据分类分级管理办法。
2. 数据安全管理办法。
3. 数据共享与开放管理办法。
4. 数据质量管理办法。
5. 数据生命周期管理办法。
6. 数据安全事件应急预案。

### 4.2 标准制定

委员会负责制定和维护以下标准：

1. 数据元标准：定义核心数据元素的命名、格式和取值范围。
2. 数据接口标准：定义系统间数据交换的格式和协议。
3. 数据质量标准：定义数据完整性、准确性、一致性要求。
4. 数据安全标准：定义不同级别数据的保护措施要求。

### 4.3 监督评估

委员会负责以下监督评估工作：

1. 每季度评估各部门数据治理执行情况。
2. 每年组织一次数据安全风险评估。
3. 每年组织一次数据合规审计。
4. 跟踪数据安全事件处置和整改情况。

## 5. 数据所有者制度

### 5.1 数据所有者定义

数据所有者是对特定数据集承担管理责任的业务部门负责人。数据所有者负责确定数据的业务含义、使用规则和访问权限。

### 5.2 数据所有者职责

1. 确定数据的分类分级属性。
2. 审批数据访问和共享申请。
3. 定期复核数据质量和完整性。
4. 配合安全审计和合规检查。
5. 参与数据安全事件调查和处置。

### 5.3 数据管理员

数据所有者可指定数据管理员协助日常管理工作。数据管理员负责数据标准执行、质量问题处理和权限管理操作。

## 6. 绩效考核

### 6.1 考核指标

数据治理绩效考核包括以下指标：

1. 数据分类分级覆盖率：目标不低于百分之九十五。
2. 数据质量问题整改率：目标不低于百分之九十。
3. 数据安全事件响应及时率：目标不低于百分之九十五。
4. 数据共享审批及时率：目标不低于百分之九十。
5. 员工数据安全培训完成率：目标不低于百分之百。

### 6.2 考核方式

考核采用季度评估和年度总评相结合的方式。季度评估由秘书处组织，年度总评由委员会全体会议审议。考核结果纳入部门年度绩效。

## 7. 附则

本章程由数据治理委员会负责解释和修订，自发布之日起施行。
