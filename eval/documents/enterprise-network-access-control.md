# 企业网络访问控制管理规范

## 文档信息
- 文档编号：SEC-NAC-001
- 版本：1.0
- 适用范围：企业网络基础设施、办公网络、生产网络和云网络

## 1. 网络区域划分

### 1.1 安全区域定义
企业网络应划分为以下安全区域：
- 互联网接入区：承载对外服务的 Web 服务器、API 网关和 CDN 回源服务器
- 办公网络区：承载员工办公终端、打印设备和会议系统
- 开发测试区：承载开发环境、测试环境和持续集成系统
- 生产核心区：承载生产数据库、应用服务器和中间件
- 管理运维区：承载堡垒机、监控系统、日志平台和配置管理
- 安全管理区：承载安全设备管理平台、漏洞扫描系统和态势感知

### 1.2 区域间访问控制
各安全区域之间应通过防火墙或安全组实施访问控制，默认拒绝所有跨区域流量。仅允许业务必需的最小访问权限，并通过白名单方式配置允许的协议、端口和地址。从低安全区域到高安全区域的访问应经过堡垒机或应用网关代理。

## 2. 网络准入控制

### 2.1 接入认证
所有设备接入企业网络前应完成身份认证和安全合规检查。有线网络应通过 802.1X 认证，无线网络应通过 WPA3-Enterprise 认证。认证服务器应验证设备证书或用户凭据，并检查设备安全状态（操作系统版本、补丁状态、杀毒软件状态）。

### 2.2 设备安全合规检查
接入企业网络的设备应满足以下安全基线：
- 操作系统已安装最新安全补丁，补丁发布时间不超过三十天
- 已安装企业统一部署的终端防护软件且病毒库为最新版本
- 已启用磁盘加密（BitLocker 或 FileVault）
- 屏幕锁定时间设置不超过五分钟
- 未安装未授权的远程控制软件

### 2.3 不合规设备处置
未通过安全合规检查的设备应被引导至隔离网络。隔离网络仅允许访问补丁下载服务器和安全修复指南。设备完成安全修复后可重新进行合规检查，通过后接入正常网络。

## 3. 远程访问管理

### 3.1 VPN 访问
远程访问企业内网应通过企业统一 VPN 网关。VPN 连接应使用 IKEv2 或 WireGuard 协议，禁用 PPTP 和 L2TP 等不安全协议。VPN 账户应与统一身份认证平台集成，并强制启用多因素认证。

### 3.2 零信任网络访问
企业应逐步实施零信任网络访问（ZTNA）架构，替代传统 VPN。零信任架构应基于用户身份、设备状态、访问上下文和数据敏感度进行动态授权。访问决策应在每次请求时实时评估，而非基于网络位置的静态信任。

## 4. 网络流量监控

### 4.1 流量采集
企业应在网络边界、核心交换和安全区域互联节点部署流量采集设备。应采集网络五元组（源地址、目的地址、源端口、目的端口、协议）、流量大小、连接时间和应用协议类型。流量数据应保留九十天以上。

### 4.2 异常流量检测
应建立网络流量基线，检测以下异常行为：
- 单个主机在短时间内与大量外部地址建立连接（扫描行为）
- 非工作时间的大规模数据传输（数据外泄）
- 与已知恶意 IP 或域名的通信（失陷主机）
- DNS 查询异常（DNS 隧道或 DGA 域名）
- 加密流量中的异常特征（隐蔽通道）

## 5. 无线网络安全

### 5.1 企业无线网络
企业无线网络应使用 WPA3-Enterprise 认证，接入密码应通过 RADIUS 服务器动态下发。企业无线网络应分为员工网络和访客网络，访客网络应与内部网络完全隔离。无线接入点应禁用 WPS 功能，SSID 广播可根据安全需要选择关闭。

### 5.2 无线信号管控
敏感区域（如数据中心、研发中心、会议室）应部署无线信号检测设备，检测未授权的无线接入点和热点。发现未授权无线设备后应在十五分钟内定位并处置。涉密区域应部署无线信号屏蔽装置。

## 6. 网络设备安全管理

### 6.1 设备配置管理
网络设备配置应纳入统一配置管理平台，定期备份配置文件。设备固件应定期更新，关键安全补丁应在发布后七天内完成更新。网络设备管理应通过带外管理网络，禁止通过生产网络直接管理核心网络设备。

### 6.2 日志与审计
网络设备应开启操作日志记录，日志应发送至集中日志平台。管理会话应设置超时时间不超过十分钟。所有网络设备的配置变更应经过审批流程，并记录变更内容、变更原因、操作人和审批人。
