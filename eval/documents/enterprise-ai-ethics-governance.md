# 星河制造集团人工智能伦理治理规范（样例）

## 1. 总则

为规范集团人工智能技术的研发和应用，防范人工智能伦理风险，保障人工智能系统的安全、可靠、可控，根据《新一代人工智能伦理规范》《生成式人工智能服务管理暂行办法》等规范，制定本规范。

## 2. 适用范围

本规范适用于集团及其下属子公司在研发、部署和使用人工智能系统的所有活动，包括但不限于：

1. 机器学习模型的训练和部署。
2. 生成式人工智能服务的提供。
3. 智能决策系统的开发和应用。
4. 自动化流程的实施和管理。
5. 人工智能辅助的人力资源决策。

## 3. 伦理原则

### 3.1 以人为本

人工智能系统的设计和应用应以服务人类为根本目的，保障人的尊严、权利和自由。人工智能应作为人类能力的增强工具，而非替代人类进行关键决策。

### 3.2 公平公正

人工智能系统应避免产生或放大歧视和偏见。模型训练数据应具有代表性，算法设计应考虑不同群体的公平性。定期评估人工智能系统对不同群体的影响。

### 3.3 透明可解释

人工智能系统的决策逻辑应可解释，用户有权知晓人工智能参与决策的程度。高风险应用应提供决策依据说明，支持人工复核和申诉。

### 3.4 安全可控

人工智能系统应具备安全防护机制，防止恶意攻击和滥用。系统应设置人工干预开关，在出现异常时能够及时停止或降级。

### 3.5 隐私保护

人工智能系统的数据处理应遵循最小必要原则，保护个人隐私。训练数据应经过脱敏处理，模型不应泄露个人信息。

## 4. 伦理风险评估

### 4.1 评估范围

以下人工智能应用应进行伦理风险评估：

1. 涉及个人信息处理的智能系统。
2. 用于人力资源决策的智能系统。
3. 面向公众提供服务的智能系统。
4. 涉及安全关键领域的智能系统。
5. 使用生成式人工智能技术的系统。

### 4.2 评估内容

伦理风险评估应覆盖以下内容：

1. 数据来源合法性和代表性评估。
2. 算法公平性和偏见检测。
3. 决策透明度和可解释性评估。
4. 安全风险和滥用可能性评估。
5. 隐私影响和个人信息保护评估。
6. 社会影响和伦理争议评估。

### 4.3 评估流程

伦理风险评估流程如下：

1. 项目立项时提交伦理评估申请。
2. 伦理委员会组织专家评审。
3. 评审意见作为项目审批的必要条件。
4. 高风险项目需制定风险缓解措施。
5. 评估报告存档备查。

## 5. 生成式人工智能管理

### 5.1 服务准入

提供生成式人工智能服务前，应完成以下准备工作：

1. 完成算法备案和安全评估。
2. 建立内容审核机制和投诉处理流程。
3. 制定服务协议和使用规则。
4. 部署安全过滤和防护措施。

### 5.2 数据管理

生成式人工智能的数据管理应满足以下要求：

1. 训练数据来源应合法合规，保留授权证明。
2. 训练数据应进行安全过滤，去除违法不良信息。
3. 用户输入数据应进行安全检测，防止注入攻击。
4. 生成内容应进行安全审核，防止有害信息输出。

### 5.3 内容安全

生成式人工智能应建立多层次内容安全防护：

1. 输入过滤：检测并拦截违规输入内容。
2. 生成控制：通过系统提示词约束生成行为。
3. 输出审核：对生成内容进行安全检测。
4. 人工复核：对高风险内容进行人工审核。

## 6. 人工智能伦理委员会

### 6.1 委员会组成

人工智能伦理委员会由以下人员组成：

1. 主任委员：由集团首席技术官担任。
2. 技术委员：由人工智能技术专家组成。
3. 伦理委员：由法务、合规和伦理学专家组成。
4. 业务委员：由各业务部门代表组成。
5. 外部委员：邀请行业专家或学术机构代表。

### 6.2 委员会职责

1. 审议人工智能伦理治理制度和标准。
2. 审批高风险人工智能应用的伦理评估报告。
3. 处理人工智能伦理投诉和争议。
4. 开展人工智能伦理培训和宣传。
5. 跟踪国内外人工智能伦理法规和标准。

## 7. 监督与问责

### 7.1 监督机制

1. 伦理委员会每季度审查人工智能系统运行情况。
2. 安全团队定期进行人工智能安全审计。
3. 用户可通过投诉渠道反馈伦理问题。
4. 外部审计机构每年进行一次独立评估。

### 7.2 问责机制

违反本规范的行为将按以下方式处理：

1. 轻微违规：给予警告并要求限期整改。
2. 一般违规：给予通报批评并取消年度评优资格。
3. 严重违规：给予行政处分并追究经济责任。
4. 构成犯罪：移送司法机关处理。

## 8. 附则

本规范由人工智能伦理委员会负责解释和修订，自发布之日起施行。
